# StockPOS Frontend

เว็บแอป StockPOS สำหรับการจัดการร้าน รองรับการใช้งานบนมือถือ แท็บเล็ต และคอมพิวเตอร์ สร้างด้วย React, CRACO, Tailwind CSS, Axios และ Socket.IO Client

## หน้าจอและฟังก์ชัน

### การเข้าสู่ระบบและสิทธิ์

- หน้าเข้าสู่ระบบ สมัครสมาชิก และเข้าใช้งานแบบผู้เยี่ยมชม
- รองรับสิทธิ์ Admin, Staff และ User
- เก็บ session token ใน browser และตรวจสอบบัญชีกับ backend เมื่อเปิดระบบ
- User เห็นประวัติออเดอร์ของตนเอง ส่วนผู้เยี่ยมชมเปิด dashboard ตรวจสอบคิวได้โดยไม่ต้องล็อกอิน

### Admin

- ศูนย์ปฏิบัติการร้านแบบ 3D สำหรับแท็บเล็ตและคอมพิวเตอร์
  - หน้าร้านแสดงออเดอร์และคิว
  - สต็อกแสดงวัตถุดิบจริงจากระบบ พร้อมข้อมูลเมื่อ hover
  - ฝั่งผู้ดูแลแสดงภาพรวมการเงิน
  - แสดงคิวลูกค้าหรือ rider ตามช่องทางออเดอร์
- หน้าขายและออเดอร์: เลือกเมนู ช่องทางขาย ชื่อลูกค้า/เบอร์โทร ตะกร้าสินค้า ส่วนลด และคูปอง
- รองรับตัวเลือกต่อเมนู เช่น ระดับหวาน น้ำแข็ง ขนาดแก้ว และท็อปปิง โดยระบบแสดงส่วนเพิ่มราคาก่อนเพิ่มลงตะกร้า และกดแก้ไขตัวเลือกของแก้วเดิมในตะกร้าได้
- เลือกวิธีชำระเงิน รับเงินสดและคำนวณเงินทอน พร้อมเปิด/ปิดกะเงินสดของผู้ใช้งาน
- จอเตรียมสินค้าแยกคิว “กำลังทำ” และ “พร้อมรับ” พร้อมส่งมอบออเดอร์และพิมพ์ใบเสร็จ
- จัดการวัตถุดิบ: เพิ่ม แก้ไข ลบ รับของเข้า ผู้ขาย ประวัติใบรับของ และ Export Excel
- จัดการเมนูและสูตรวัตถุดิบ (BOM)
- หน้าการเงิน: กรองวันที่ เพิ่ม/แก้ไข/ลบค่าใช้จ่าย เพิ่ม/แก้ไข/ลบรายการขาย และ Export Excel

### Staff

- หน้าขายแบบเน้นงานหน้าร้าน ใช้งานได้ดีบนมือถือและเดสก์ท็อป
- สร้างออเดอร์ ระบุชื่อลูกค้า/ชื่อเล่นและเบอร์โทรได้ตามต้องการ
- ใช้ส่วนลดจำนวนเงินหรือเปอร์เซ็นต์
- ตรวจสอบและใช้คูปองก่อนยืนยันออเดอร์
- ดูคิวงาน และเปลี่ยนสถานะออเดอร์

### User และผู้เยี่ยมชม

- User ดูประวัติการสั่งซื้อและสถานะออเดอร์ที่สัมพันธ์กับบัญชีหรือเบอร์โทรของตน
- ผู้เยี่ยมชมดู dashboard คิวออเดอร์ทั้งหมดได้ทันที และกรอกเบอร์โทรเพื่อค้นหา/กรองรายการของตน
- แสดงชื่อเล่น/ชื่อลูกค้า เลขคิว ช่องทาง และรายการสินค้า

## การทำงานของส่วนลดและคูปอง

หน้า POS แสดงยอดก่อนลด ส่วนลดหน้าร้าน ส่วนลดคูปอง และยอดสุทธิแยกกันชัดเจน

- ส่วนลดหน้าร้านเลือกเป็นบาทหรือเปอร์เซ็นต์ได้
- กรอกรหัสคูปองแล้วกด “ใช้คูปอง” เพื่อให้ backend ตรวจสอบ
- backend เป็นผู้คำนวณและบันทึกยอดจริง ป้องกันคูปองหมดอายุ ใช้เกินสิทธิ์ หรือยอดไม่ถึงขั้นต่ำ
- การเปลี่ยนตะกร้าหลังใช้คูปองควรตรวจสอบคูปองอีกครั้งก่อนยืนยันออเดอร์

## การตั้งค่าตัวเลือกเมนู

Admin ไปที่ **เมนูสินค้า** แล้วเพิ่ม “ตัวเลือกเมนู” ในเมนูที่ต้องการ กำหนดชื่อกลุ่ม จำนวนขั้นต่ำ/สูงสุด และแต่ละตัวเลือกพร้อมราคาเพิ่ม/ลดได้ เมนูที่มีตัวเลือกจะแสดงหน้าต่างให้พนักงานเลือกก่อนลงตะกร้า ส่วนเมนูปกติยังเพิ่มได้ทันที หากเลือกผิด ให้กด **ปรับความหวาน / ท็อปปิ้ง** ที่รายการนั้นในตะกร้า ระบบจะคงจำนวนแก้วเดิมและรวมกับรายการที่มีตัวเลือกเหมือนกันโดยอัตโนมัติ

## จอเตรียมสินค้าและใบเสร็จ

Admin เปิด **จอเตรียมสินค้า** จากแถบเมนู เพื่อเห็นบัตรคิวแบบอ่านง่ายบนแท็บเล็ตหรือจอครัว แต่ละคิวเดินตามสถานะ `COOKING → READY → COMPLETED` โดยจะแสดงเมนู ความหวาน/ท็อปปิ้ง ชื่อลูกค้า และช่องทางขาย ปุ่ม **ใบเสร็จ** เปิดหน้าต่างพิมพ์ที่มีรายการสินค้า ส่วนลด วิธีชำระ และเงินทอน

## การชำระเงินและกะเงินสด

หน้า POS รองรับเงินสด, QR พร้อมเพย์, โอนเงิน, บัตร และอื่น ๆ เมื่อเลือกเงินสด ผู้ใช้งานต้องเปิดกะก่อน แล้วกรอกยอดที่รับเพื่อให้ระบบแสดงเงินทอนทันที ปุ่มเปิด/ปิดกะอยู่ในส่วนการชำระเงินและหน้าร้าน เมื่อปิดกะให้กรอกยอดเงินที่นับได้ ระบบจะแสดงยอดคาดการณ์และยอดต่างให้ตรวจสอบ

## การรับวัตถุดิบเข้า

หน้า **วัตถุดิบ** มีฟอร์ม “รับวัตถุดิบเข้าคลัง” สำหรับเลือกผู้ขาย ระบุวันเวลารับของ เพิ่มวัตถุดิบได้หลายรายการต่อใบ และกรอกต้นทุนจริงต่อหน่วย ระบบคำนวณยอดรับรวมและปรับจำนวนคงเหลือกับต้นทุนเฉลี่ยของวัตถุดิบหลังบันทึกสำเร็จ ประวัติใบรับของล่าสุดจะแสดงใต้ฟอร์ม พร้อมทางลัดเพิ่มผู้ขายใหม่

## การเชื่อมต่อ Backend

กำหนด URL ของ backend ด้วย environment variable:

```env
REACT_APP_API_URL=https://your-backend.example.com
```

หากไม่กำหนด ระบบจะใช้ URL production ที่ตั้งไว้ใน `src/App.jsx` โดยอัตโนมัติ

Frontend เรียก API เพื่อดึงออเดอร์ สินค้า สต็อก การเงิน และใช้ Socket.IO เพื่ออัปเดตสถานะออเดอร์แบบ real-time

## การติดตั้งและรัน

ติดตั้งแพ็กเกจ:

```bash
npm install
```

รันโหมดพัฒนา:

```bash
npm run dev
```

สร้าง production build:

```bash
npm run build
```

รัน production build ในเครื่อง:

```bash
npm start
```

`npm start` จะสร้าง build ก่อนอัตโนมัติหากยังไม่มี แล้วเปิด static server ตามค่า `PORT` (ค่าเริ่มต้น 3000)

## โครงสร้างสำคัญ

```text
src/App.jsx                         สถานะระบบ, session, API และ real-time sync
src/components/ui/GlassLayout.jsx   หน้าจอ Admin: POS, สต็อก, เมนู, การเงิน
src/components/ui/StaffWorkspace.jsx หน้าจอ Staff
src/components/ui/UserOrderStatus.jsx หน้าประวัติและสถานะออเดอร์ของ User
src/components/ui/AnonymousOrderStatus.jsx หน้า public dashboard ตรวจสอบออเดอร์
src/components/ui/OperationsRoom3D.jsx ศูนย์ปฏิบัติการร้านแบบ 3D
src/assets/                          ภาพประกอบและสินทรัพย์ของ UI
```

## เทคโนโลยี

- React 19 และ React DOM
- Tailwind CSS และ PostCSS ผ่าน CRACO
- Axios สำหรับ REST API
- Socket.IO Client สำหรับข้อมูล real-time
- Three.js และ React Three Fiber สำหรับศูนย์ปฏิบัติการ 3D
- SheetJS (`xlsx`) สำหรับ Export Excel

## หมายเหตุการแสดงผล

- ออกแบบให้ responsive โดยเน้น mobile และ desktop
- ฉาก 3D จะแสดงเฉพาะหน้าจอแท็บเล็ต/คอมพิวเตอร์ เพื่อไม่ให้มือถือใช้ทรัพยากรเกินจำเป็น
- มือถือจะแสดง fallback ที่อ่านง่ายและใช้งานส่วนจัดการร้านได้ครบ
